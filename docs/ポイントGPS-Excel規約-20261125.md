# ポイントGPS Excelファイル規約

緊急ポイントの地図上の位置(GPS：緯度・経度・標高)を管理するためのExcelファイルの規約

## 管理体制

- 管理責任者： みのお山麓保全委員会 事務局長

## 管理方式

- ファイル形式： Excel（ファイルタイプ： .xlsx）
- ファイル名： ポイントGPS-yyyymmdd.xlsx （例： ポイントGPS-20250910.xlsx）  
  ファイル名は保存時、または後から別の名前にしても可とする。
- シート名： ポイントGPS（固定）
- 項目： Excelの列名（固定）

| 項目名(列名) | 内容 | 例示 | 必須・任意 |
| --- | --- | ---: | :---: |
| ポイントID | X-nn形式の文字列<br>（X: 英大文字, nn: 数字2桁） | B-10 | 必須 |
| 名称 | 場所等を示す名称 | こもれび展望所 | 必須 |
| 英語名 | 英語表記での名称 | Komorebi Viewpoint | 任意 |
| 緯度 | 10進形式の緯度（北緯） | 34.85544 | 必須 |
| 経度 | 10進形式の経度（東経） | 135.47995 | 必須 |
| 標高 | 地図上の高さ（単位: m） | 374.6 | 任意 |
| 備考 | ポイントに関する備考、留意事項 | | 任意 |
